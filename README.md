# Taschengeld-Taschen PRO

Kindgerechte Handy-App/PWA für Taschengeld nach dem 3-Taschen-System.

## Enthalten

- mehrere Kinder/Profile
- Eltern-Modus mit PIN
- Spaß-Tasche
- Ziel-Tasche
- 5%-Zinsen-Tasche
- Monatszinsen
- Aufgaben-/Belohnungssystem
- Ziel-Fortschritt
- Verlauf
- lokaler Speicher im Browser per `localStorage`
- PWA-Manifest und App-Icons

## Standard-PIN

`1234`

## Lokal starten

```bash
npm install
npm run dev
```

## Für GitHub Pages bauen

```bash
npm run build
```

Der fertige Build liegt danach im Ordner `dist`.
