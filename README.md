# Taschengeld-Taschen PRO – GitHub Pages Version

Diese Version braucht keinen Build und kein `npm install`.

## So veröffentlichst du sie auf GitHub Pages

1. ZIP entpacken.
2. Alle Dateien direkt ins GitHub-Repository hochladen:
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.webmanifest`
   - Ordner `icons`
3. In GitHub auf **Settings → Pages** gehen.
4. Bei **Source** auswählen:
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/root`
5. Speichern.
6. Nach kurzer Zeit ist die App online.
